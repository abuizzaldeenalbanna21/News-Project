# News frontend

React and Vite frontend for the news application. For setup, environment
configuration, and project-wide instructions, see the [project README](../README.md).

Available commands:

```bash
npm ci
npm run dev
npm run lint
npm run build
```

Set `VITE_API_URL` in a local `.env.local` file to point the frontend at a
deployed API. See [`.env.example`](.env.example).
